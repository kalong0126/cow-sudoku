# 小牛数独

这是一个可在手机、平板和桌面浏览器运行的 PWA 单页游戏。

## 本机运行

在当前目录启动静态服务：

```powershell
python -m http.server 8080
```

电脑浏览器打开：

```text
http://localhost:8080
```

手机或平板需要和电脑在同一 Wi-Fi 下，打开电脑的局域网 IP，例如：

```text
http://你的电脑IP:8080
```

## 安装到手机/平板

- Android Chrome/Edge：打开网页后，菜单中选择“添加到主屏幕”或“安装应用”。
- iPhone/iPad Safari：打开网页后，分享按钮中选择“添加到主屏幕”。

离线缓存和安装能力需要通过 `http://localhost`、局域网 HTTP 或 HTTPS 访问；直接双击 `index.html` 只能试玩，不能启用 PWA 离线缓存。

## 连开十局

- 点击“连开十局”后，从第 1 局开始连续进行 10 局，每局随机生成棋盘尺寸和难度。
- 当前局未结束时不能再次开新局；十局状态、题面、标记和生命值会保存在浏览器本地，刷新页面后继续原局。
- 每局胜利或生命值耗尽都会记录难度、结果、剩余心数和单局耗时；第 10 局结束后展示总耗时并恢复普通游戏。
- 首页只保留“查看统计”入口，统计在弹窗中展示；挑战过程中可点击“退出挑战”立即结束，已完成的局数会以“已退出”记录保留。
- 统计弹窗可按当前 IP 选择本浏览器保存的历史挑战，最多保留最近 50 次挑战。
- 线上访问时通过 `api64.ipify.org` 获取当前公网 IP，并随十局报告保存在当前浏览器的 `localStorage` 中；本机 `localhost` 调试时显示 `127.0.0.1`。

当前项目仍是纯静态 PWA，统计不会上传到服务器或跨设备汇总。如需管理员集中查看所有玩家记录，需要后续增加后端接口和数据库。
